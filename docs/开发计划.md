# 阶段开发计划

更新时间：2026-10-23

## 1. 当前定位

Open Sales Assistant 是一个可自部署的开源销售助手 starter kit。当前新增通用线索工作台，供早期客户访谈和单人/小范围试用；在验证目标团队前，不为某个垂直行业锁定产品模型。

当前不是商业 SaaS 平台，也不包含托管计费、多组织开通或平台运营后台。

## 2. 当前模块

```text
open-sales-assistant/
  public/             # 前台咨询 + 后台管理页面
  server/             # Express 后端与线索 API（当前共用单体）
  data/               # 本地 JSON demo 数据
  uploads/            # 上传文件，默认不提交仓库
  docs/               # 项目文档
  package.json
  .env.example
```

## 3. 已完成功能

### 客户咨询端

- 昵称注册、随机密码和登录态记忆。
- 客户资料维护。
- 聊天历史保存。
- AI 基于知识库答复。
- 可附带图片素材。
- 证书查询 demo 流程。

### 后台管理

- 管理员登录与接口鉴权。
- 客户列表、搜索、排序、分页和删除。
- 客户详情、聊天记录、AI 画像和跟进记录。
- 通用线索创建、编辑、搜索、阶段管理、负责人和下次跟进日期。
- CSV/XLSX 批量导入，按手机号/邮箱去重。
- 今日及逾期待跟进队列、电话/消息/会议/邮件沟通时间线。
- 基于线索摘要、跟进记录和销售知识生成待人工审核的 AI 建议草稿。
- 超级管理员、主管和销售角色；线索按团队和负责人限制访问。
- 基础后台操作日志，记录关键写操作。
- 文字、图片、文档素材上传。
- AI 素材分析和待审核建议。
- 知识摘要、销售话术、FAQ、顾虑应对维护。
- 证书新增、删除、批量导入和查询。
- 咨询配置维护。

### 数据与部署

- JSON 文件默认存储和可选 PostgreSQL storage adapter；JSON 导入 PostgreSQL 迁移命令。
- `schemaVersion` 迁移至 4，兼容团队成员、角色和线索归属。
- JSON 与 PostgreSQL 的每日自动备份、手动备份和恢复说明。
- 写事务串行化；PostgreSQL 跨实例行锁，JSON 单进程互斥锁。
- 数据导出接口。
- PM2、Nginx、宝塔部署参考。

## 4. 下一阶段优先级

### P0：开源可运行版本（已完成）

- 确保 README、license、贡献指南、安全说明齐全。
- 确保 demo 数据安全、可解释、可替换。
- 增加基础 API 测试和启动验证脚本。
- 增加一键重置 demo 数据脚本。

### P1：用户验证与规模化

- 按[客户验证执行包](客户验证执行包.md)招募并访谈 5-10 个小型 B2B 团队，记录当前线索来源、跟进流程和漏单场景。
- 观察试用者是否持续维护负责人、沟通记录和下一次跟进。
- 邀请 1-2 个小团队做受控试点，收集权限边界、备份恢复和并发体验反馈。
- 随数据量增长将 PostgreSQL 的 JSONB 状态拆成关系表，并加入真实 PostgreSQL 集成测试。
- 验证 AI 草稿是否节省准备时间，并记录采纳/修改反馈。

### P2：知识库质量增强

- AI 建议采纳前可编辑。
- 知识库版本历史和回滚。
- 素材搜索、编辑、批量管理。
- AI 用量日志和成本估算。
- Prompt 评测样例。

### P3：自部署增强

- 改进 Docker 部署。
- 持续完善 PostgreSQL 关系表迁移，同时保留 JSON 文件存储。
- 数据恢复后台。
- 生产部署 checklist。
- CRM、表单、表格和团队通讯工具连接器示例。
